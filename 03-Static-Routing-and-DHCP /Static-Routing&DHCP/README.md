# Static Routing and DHCP Lab

## Overview
Configuring static routing between routers and DHCP to automatically assign IP addresses to end devices using Cisco Packet Tracer.

## Key Topics
- Static Routing
- DHCP Configuration
- Automatic IP Address Assignment
- Default Gateway Configuration
- Network Connectivity Testing

## Tools
- Cisco Packet Tracer

## Verification
- `show ip route`
- `show ip dhcp binding`
- `show ip dhcp pool`
- `ping` connectivity tests

## Learning Objectives
Understanding how static routes enable communication between different networks and how DHCP simplifies IP address management.
