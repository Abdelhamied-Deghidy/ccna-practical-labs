# VLANs and Trunking Lab

## Overview
Configuring VLANs and trunk links between two Cisco switches using Packet Tracer.

## VLANs
- VLAN 10: IT Department
- VLAN 20: أHR Department

## Devices
- 2 Cisco 2960 Switches
- 4 PCs

## Configuration
- VLAN Creation
- Access Port Assignment
- 802.1Q Trunking

## Verification
- `show vlan brief`
- `show interfaces trunk`
- Ping Connectivity Tests

## Tools
Cisco Packet Tracer
